KnightLoader

Every instance the extension can send a link, a selection, or a page to. No account, relay or password is stored here: sending to one points a small window (or the toolbar popup) at that address, and the normal sign-in for that instance applies exactly as it would if you had typed the address yourself. The one marked "Default" is used when you have not chosen otherwise.
