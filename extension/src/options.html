KnightLoader

The address of the instance a link, a selection, or a page should be sent to — whatever you would type into your own browser to reach it. No account, relay or password is stored here: opening it points a small window at that address, and the normal sign-in for that instance applies exactly as it would if you had typed the address yourself.

There is no hosted service this points at by default — it is always the address of one instance you run.
